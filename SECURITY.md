# Security Policy

## Reporting a Security Vulnerability

If you believe you have found a security vulnerability in this project, please do not open a public issue.

Instead, please report it privately by using GitHub Security Advisories for this repository:

https://github.com/Aryan21-Sutariya/skills-introduction-to-repository-management/security/advisories

If necessary, contact the maintainers directly at security@example.com.

Please include as much detail as possible so we can investigate and fix the issue quickly.

## Supported Versions

This project currently supports the latest main branch and any actively maintained release.

## Disclosure Policy

We will acknowledge valid reports as quickly as possible and work to resolve them in a timely manner. We appreciate responsible disclosure and will coordinate with reporters before public disclosure when appropriate.
